Week 2: Pattern Matching

👀 See this → do this

  • "equivalent to" → Line 1 is the given expression. Type each choice as Line 2. The choice that hides Line 1 wins.
📝 Practice Drills ▼

👀 See this → do this

  • A table + "linear," "line of best fit," or "model" → y_1 ~ mx_1 + b. Read m and b.
  • "exponential" → y_1 ~ ab^{x_1}.
  • "quadratic" → y_1 ~ ax_1^2 + bx_1 + c.
  • Pick the choice closest to the numbers Desmos shows.

Week 3: Click & Read

👀 See this → do this

  • "minimum" or "maximum" or "greatest value" → click the bottom or top. Read the y.
  • "for what x is it smallest or largest" → same point. Read the x.
  • "solution," "zero," or "x-intercept" → click where it crosses the x-axis.
📝 Practice Drills ▼

👀 See this → do this

  • "circle" + "radius," "diameter," or "center" → find the left and right edges (and top and bottom). Halfway between is the center. Half the width is the radius.
